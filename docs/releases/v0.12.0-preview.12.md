# SYSTIVRA v0.12.0 Preview 12 — Recording, Export and UI Fixes

**Developer test preview**, English-only interface, dark visual system, no account required. This version is not certified pixel-perfect, production-signed or approved by Google Play.

## Improvements

- Switching between saved recording sessions immediately hides the previous session's data. The selected-session UI waits for actual SQLite readings and ignores late results from earlier selections.
- Secure local CSV export: normalizes CR/LF, other controls and Unicode row separators; neutralizes spreadsheet formula-like values including invisible-prefix variants; preserves ordinary measurements and standard quoting.
- Improved compact-height accessibility: Settings, About, History, Recording Library and Tool Catalog can scroll their full content when necessary. Standard-size reference-board geometry is preserved as far as the Compose layout permits.
- Additional regression tests for race conditions, formula/row injection and a short-viewport action.

## Exact-source build assurance

The release publisher waits for **Android CI success at the same main commit**, including application-ID audit, static security checks, Gradle lint, JVM tests, instrumentation-test compilation, debug APK and unsigned AAB assembly. Downloaded binaries are checked as ZIP archives, packaged with the exact source and artwork, and accompanied by SHA256 checksums.

This *fast developer preview* deliberately does not claim that every connected emulator UI test, screenshot comparison, four-viewport responsive audit or real cold-start Splash capture has passed. See their independent workflows and [issue #26](https://github.com/bren-wp/SYSTIVRA/issues/26). Do not use the unsigned AAB for direct Google Play submission; production Play signing keys are private.

## Included archives

A debug-signed APK, an unsigned AAB, source ZIP, Play artwork ZIP, original design references labeled **not screenshots**, these release notes and SHA256SUMS.txt. Real app screenshots must come from independent emulator capture rather than the source SVG designs.
