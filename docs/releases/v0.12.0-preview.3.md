# SYSTIVRA v0.12.0-preview.3 — private data hardening, dead-code and 37-screen QA audit

**Security-hardened development preview; NOT independently penetration-tested or 1:1 certified.**

## Android security improvements

- **SQLite queue memory safety:** an atomic, race-safe gate limits queued complete hardware snapshots to 32 when the disk is slower than live sampling. Control actions remain ordered and are not silently discarded. On overflow the app indicates that samples were skipped; the user can still stop recording.
- **Private device data transfer:** explicitly excludes app-private databases, recording sessions and preferences from cloud backup and device-to-device transfer using Android 12+ `dataExtractionRules`, alongside the preexisting `allowBackup=false` and `fullBackupContent=false`.
- **Cleartext traffic:** explicitly disabled. Application still declares no INTERNET permission, tracking SDK or cloud backend.
- **Safe error messages:** raw SQLite/Android provider exceptions are no longer concatenated into recording, CSV/JSON/PDF/Android Sharesheet or benchmark UI errors.
- **Race-safe accounting:** concurrent producer saturation, queue release and underflow are covered by new JVM tests.
- **Automated static regression audit:** checks manifest/exported Android components, permission changes, common dangerous API sinks and hardcoded secrets, backup policy, producer cap, navigation registration, pinned Gradle dependency usage and private-declaration/website dead-code candidates. Android CI fails on blocking findings and uploads the audit report.
- Website privacy documentation now accurately describes PDF and explicit user-requested Android Sharesheet exports; pinned AGP security documentation updated to 9.5.1.
