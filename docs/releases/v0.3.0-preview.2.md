# SYSTIVRA v0.3.0-preview.2 — UI and navigation refinement

**Developer preview. Not a production or 1:1-certified build.**

This incremental release includes the functionality in v0.3.0-preview.1 plus:

- Fixed nested back-stack behavior. Detail pages return to the previous in-app destination instead of unexpectedly jumping to Dashboard.
- Improved SYSTIVRA visual identity: gradient device card, rich dark panel surfaces, purple navigation selection, consistent hardware Material icons, native gradient splash logo.
- Compose UI instrumentation smoke tests for Dashboard and nested navigation; bundled with emulator QA workflow.
- Continued 37-screen screenshot evidence generation and visual-difference reporting.

### Release files

- SYSTIVRA-v0.3.0-preview.2-debug.apk — developer-signed debug APK.
- SYSTIVRA-v0.3.0-preview.2-unsigned.aab — unsigned bundle, NOT ready for Google Play.
- SYSTIVRA-v0.3.0-preview.2-source.zip — exact tagged source, including website and branding.
- SHA256SUMS.txt — integrity manifest.

### Honest status

The 37 visual references are concepts. Pixel-perfect parity is **not established**. The current build includes live Android hardware providers, user-controlled local capture, CPU benchmark and basic diagnostics, while permanent data storage, full component test coverage, cross-app overlay and some restricted metrics are unfinished. No automatic optimization, fabricated health score or fictitious FPS reading is offered.

Release compilation, unit tests and packaging are mandatory; on-device visual/accessibility and privacy-policy acceptance remain separate future gates.
