# SYSTIVRA v0.10.0-preview.2 — recording safety and navigation

**DEVELOPER PREVIEW — not production-ready, not pixel-perfect certified.**

## Included changes
- Explicit confirmation before permanently deleting every saved recording session and its samples. Cancel does not invoke deletion.
- Foreground recording stops as the activity leaves the foreground; SQLite storage is closed when its coroutine is cancelled.
- Nested screens preserve the proper bottom-navigation root selection.
- Removed development inventory text and an inaccurate statement about persistent recording from the visible app interface.
- Added a Compose instrumented test for destructive-action confirmation.
- Android versionCode 12; unchanged `com.brendigo.systivra` application ID.

## Verification and open risks
- Android lint, unit tests, instrumented UI tests, APK/AAB builds and SHA256 checks are required before publishing the preview.
- 37 original reference designs are **concept references**, not Android screenshots.
- **0/37 screens have certified 1:1 comparisons**. System Splash must be captured separately.
- Real-device coverage, accessibility, complete functional matrix, security review, and Google Play acceptance are **not yet complete**.
- This developer preview is not a signed Google Play production release.

## Release artifacts
- Debug APK for developer testing (not a production-signed APK)
- Unsigned AAB (must be properly signed for Play)
- Full source ZIP, Google Play artwork ZIP, 37 original reference design ZIP
- SHA256SUMS.txt

Older `v0.10.0-preview.1` is preserved unchanged. Screenshots in the reference-design ZIP must not be presented as genuine application captures.
