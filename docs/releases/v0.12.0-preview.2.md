# SYSTIVRA v0.12.0-preview.2 — consistent SVG iconography and working temperature units

**Actual Android developer pre-release. Not production-signed or certified 1:1.**

## Improvements

- Replaced the original four reference-row glyphs (diamond, list, target, signal) with deterministic 18dp native vector icons. Colors, icon tiles, 69dp card dimensions, original 82dp spacing and responsive behavior are preserved. The symbol no longer depends on manufacturer Unicode glyph fonts or emoji replacement.
- Shared metric cards use an onClick Material3 Card with native clipped pressed/ripple feedback, preserving correct touch and accessibility behavior.
- Enabled the previously informative-only **Settings → Units** feature: choose **Celsius (°C)** or **Fahrenheit (°F)**, locally persisted. This affects real Android temperature readings in live metric and battery/thermal detail screens, with no account or external service.
- Temperature conversions happen **only in displayed UI strings**, only for Celsius readings explicitly identified as temperatures, using the original Android reading values. CSV, JSON, PDF, history, data sources and physical measurements remain unchanged. Invalid, unavailable and non-Celsius values are never interpreted as zero.
- Battery detail chart now uses the same alias-aware, 0–100% validated charge-level samples already used by other chart screens. A temperature or current reading cannot replace battery percentage.
- Added tests for unit conversions, persistence, settings interaction and a live battery reading in the selected temperature scale.

## Native visual evidence

- Comparison method: 36 original Android in-app route screenshots captured at native 390×844 vs the original SVG files, without rescaling or retouching; Splash is separately captured.
- Last fully validated baseline before these changes (v0.12.0-preview.1): 36/36, **28.371% changed pixels**, **2.537% RGB MAE**, and 25/28 checked text glyph baselines exactly matching original vector y positions, with three within 1px.
- This new edition must pass new real screenshots and native visual comparisons, plus four size/responsive captures and instrumented UI tests. The original 37 designs are never presented as device screenshots.
- Native Android system bars, font renderer, fallback glyphs, hardware availability and device differences prevent certification without independent manual and physical-device review. **0 of 37 designs are certified pixel-perfect.**
