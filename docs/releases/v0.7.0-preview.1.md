# SYSTIVRA v0.7.0-preview.1 — Stability & Google Play branding

**Developer preview. This is not a claim of Google Play approval, zero crashes or pixel-perfect parity.**

## Android code improvements
- Wrote CSV and JSON reports using `Dispatchers.IO` instead of Compose's UI thread.
- Moved optional local app usage statistics retrieval off the UI thread.
- Fixed Screen Catalog navigation and made Usage Access privacy wording more accurate.
- Added stricter screenshot capture: does not change the emulator's native window size/density, verifies SYSTIVRA has the focused window, logs unexpected system dialogs and fails on invalid/duplicate captures.
- The previous screenshot artifact was invalid: many images showed System UI/Quickstep ANR dialogs instead of the app. Those images are **not** recommended for Google Play.

## Branding and Google Play artwork
- [Google Play artwork directory](../../brending/google-play/) with editable SVG sources and generated assets.
- Official store icon: `brending/google-play/assets/icon-512.png`, 512×512 RGBA PNG, less than 1 MB.
- Feature graphic: `brending/google-play/assets/feature-graphic-1024x500.png`, 1024×500 RGB PNG.
- English listing metadata plus eight *design concepts* (1080×1920) placed under `concepts-NOT-FOR-PLAY`.
- The image-generation workflow creates a versioned [graphics ZIP](../../brending/google-play/assets/SYSTIVRA-Play-Graphics.zip).
- **Do not upload conceptual images as Play screenshots.** Genuine screenshots require a stable on-device or emulator capture and manual review.

## Files attached to this release
- `SYSTIVRA-v0.7.0-preview.1-debug.apk`: debug-signed Android APK, for tests only.
- `SYSTIVRA-v0.7.0-preview.1-unsigned.aab`: unsigned release bundle; production signing is required.
- `SYSTIVRA-v0.7.0-preview.1-source.zip`: complete tagged source, marketing assets and documentation.
- `SHA256SUMS.txt`: verified checksums for the release assets.

## Open acceptance gates
- Full 1:1 visual comparison of all screens, and separate capture of system Splash.
- Device matrix crash/ANR, accessibility, battery and sensor testing.
- Play Data Safety and privacy disclosures including optional Usage Access.
- Secure upload-key signing, real Google Play internal test installation and listing review.
- Further hardware/diagnostic modules remain device-dependent or incomplete.

Package ID `com.systivra.app`, `targetSdk=36`, `minSdk=24`, English-only UI and no account/onboarding.
