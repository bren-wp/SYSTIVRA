# SYSTIVRA v0.12.0-preview.1 — measured visual parity, real screenshots and truthful battery trends

**Development pre-release, not 1:1 certified, not production signed.** Built from the actual Android source; not a concept mock-up.

## What's new since v0.11.0-preview.2

### Original-screen visual fidelity

- Applied original SVG-normalized midnight background gradient to all native screens rather than physical-pixel diagonal blending.
- Recalibrated the 88 × 88 SYSTIVRA hero ring, its cyan/blue/purple arc radius, geometry and color-stop distribution.
- Restored original `#2BD9C5` measured-chart color, dashed chart guides, card outlines, corner radii and reference layout geometry.
- Corrected shared Compose title/subtitle/card baselines by comparing actual 390 × 844 emulator glyph pixels with original SVGs. The reference baseline fixture checks 28 text regions across 4 screens, with **25 matching exactly and 3 within 1 physical pixel** in the last validated comparison.
- Added aligned first viewports for Network Details, Alerts, Diagnostic Results, Performance HUD, Reports & Export and Charging Analysis while routing actions to real Android detail/control screens.
- All native 36/36 non-Splash screen comparisons at the last verified benchmark measured **28.371% raw changed pixels and 2.536% RGB mean absolute error** (down from 49.828% / 3.383% before visual parity work). These values include native OS bars and font rendering, and **do not establish pixel-perfect certification**.
- Kept eight genuine previously captured Android emulator screenshots in README, distinguished from original design concepts. They are not manually approved Google Play screenshots.

### Actual functionality and safety

- Preserved 63 route destinations and real interactive actions, device measurement sources, history, local storage, notifications/overlay preview limitations, responsive layout and English-only navigation.
- Added local, user-requested multi-page PDF export, CSV/JSON and optional Android Sharesheet; preserved private SQLite session data.
- Fixed battery percentage trend reading to match **named** charge-level fields, not the first entry in Android battery arrays. This prevents temperature or current values from appearing as charge on Live Monitor, Charging Analysis and fullscreen charts.
- Missing/invalid readings remain unavailable; chart points use only finite Android percentages within 0–100. No synthetic benchmark, chart or hardware temperature values.
- Added regression checks for reordered, absent, legacy and invalid battery metrics, original screen geometry, navigation, PDF export, and text baselines.
- No login or INTERNET permission.

### Version and distribution

- Package: `com.brendigo.systivra` (unchanged from previous preview).
- Android `versionCode 15`, `versionName 0.12.0-preview.1`; minimum Android API 24, target API 36.
- New APK is **debug-signed** for local testing; the AAB is **unsigned**. Neither is a production-signed Play Store update.
- Existing v0.11 releases and tags remain immutable. No private signing keys or secrets are stored in the repository.

## QA and explicit limitations

Release automation builds and tests the real Android app, checks its package/version, verifies checksums and validates that independently executed native 390 × 844 visual QA, responsive screenshots, cold-start Splash QA and connected emulator tests succeed on the exact Android source commit.

**0/37 original screens are independently certified pixel-perfect.** Native status/navigation bars, platform font rasterization, device-specific values and unsupported Android APIs can differ. Real-device accessibility review, full 37-screen manual visual sign-off, cross-application overlay implementation and microphone/camera test permissions are still outstanding.

**These assets are for development and testing, not Google Play production:**

- `SYSTIVRA-v0.12.0-preview.1-debug.apk` — debug-signed installation package
- `SYSTIVRA-v0.12.0-preview.1-unsigned.aab` — not upload-ready until authorized signing
- `SYSTIVRA-v0.12.0-preview.1-source.zip` — exact release source
- `SYSTIVRA-v0.12.0-preview.1-play-artwork.zip` — logo/icon/feature art; not screenshots
- `SYSTIVRA-v0.12.0-preview.1-reference-designs-NOT-screenshots.zip` — design concepts only
- `SHA256SUMS.txt` — integrity hashes for all release files

To publish via Google Play, a separately secured upload signing key and additional production testing are required.
