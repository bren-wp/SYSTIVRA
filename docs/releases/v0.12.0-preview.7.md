# SYSTIVRA v0.12.0-preview.7 — focused functional screens without excessive scrolling

**Native Android developer preview**, not a production-signed Play bundle or 37/37 pixel-perfect certification.

## Actual usability changes
- Shorter reference-overview routes: CPU, GPU, RAM, storage, battery, thermal, display, Android system and sensors now keep their original header/hero and four actions, but remove the 116dp empty spacer and the duplicated below-the-fold measurements list. Tapping a metric displays the real measured value, source and optional copy action in an accessible dismissible dialog **without any forced scrolling**.
- **Nine dedicated offline searchable readings screens**, separate from their overview. Real Android measurements are still shown with source and "Unavailable" where the platform does not expose a reading. The hero on non-chart detail screens and a short "All device readings" action lead to the relevant browser.
- Benchmark, CPU cores, session analysis, app usage and selected health/privacy/sensor summary screens no longer append a long second data page. Reference rows show quick dialogs or navigate straight to their own full functional controls via a clearly labeled shortcut.
- Dashboard and Settings keep their four original SVG rows and remove a long secondary list of unrelated shortcuts; retain immediate paths to Hardware Explorer, Screen Catalog and About. The feature catalog is now **searchable** to locate a function by name instead of endless scrolling.
- Keep 62dp accessible bottom tabs, real Android navigation insets and 8dp gutter, dark SVG palette, offline privacy, native measured data and separate CSV/JSON/PDF export controls.

## Functional and regression acceptance
- Keep existing functional routes and relevant tests, including temperature unit persistence, hardware-details copy/search behavior, navigation to About and Screen Catalog, benchmark selection, system navigation safe-area geometry.
- Expand actual emulator smoke QA to the nine dedicated Android readings pages.
- Release is gated on exact source SHA Android lint + JVM tests, connected emulator UI test suite, original 36 in-app 390x844 SVG pixel/color diagnostics (plus Splash), responsive viewport tests including 130% font, actual pre-launch Splash recording, static code audit, SHA256 validation and all attached real screenshots. Tests must not be weakened.

## Developer artifacts after successful gate
Debug-signed APK, unsigned AAB, exact source ZIP, artwork and reference design ZIP (clearly labeled concepts), unmodified Android emulator screenshot bundles, dialog evidence, checksums.

## Not yet certified
Zero-difference visual 1:1 across all 37 reference screens, all physical-device OS navigation modes and OEMs, Play upload signing and independent security assessment are **outstanding**. The 36 reference-first viewport reports remain quantitative diagnostics, not proof of zero error. Interactive dialogs and dedicated readings are purpose-built functional states and are not represented as original SVG stills.
