# SYSTIVRA v0.11.0-preview.2 — SVG-aligned pixel geometry and UI refinement

**Developer preview, not production-signed and not yet certified 1:1.**

## Changes

- Corrected the shared page background from a **vertical** gradient to the exact **diagonal top-left → bottom-right** direction defined by all original 390 × 844 SVG source boards.
- Rebuilt the shared SYSTIVRA hero to respect the SVG's **88 × 88 pixel ring bounding box**, **11 pixel stroke**, **x=78/y=272 center**, **113° accent arc**, explicit cyan/blue/purple linear accent and **x=143 logo text alignment** at the reference viewport.
- Matched first-viewport reference action-card starts to the source grid (**359, 441, 523, 605 pixels** on card-based screens; chart screens use **402, 484, 566, 648**), preserving **350 × 69 px** cards and visually consistent 13 px gaps.
- Aligned shared row chevrons and bottom navigation label placement to the original 390 px design while preserving native 48–62dp tap targets and Android navigation controls.
- Aligned native status and navigation **background colors** to the reference palette without hiding Android's native system buttons or forging a fake status clock.
- Added stable Compose test tags for reference heading, hero ring, hero title and metric cards plus a real emulator geometry test for dimensions, positions and 82dp row spacing.
- Preserved Android's real measurements, 37 original reference compositions, live sensors, bounded benchmark safety, recording, privacy, history and English-only, account-free navigation.
- Android `versionCode 14`, `versionName 0.11.0-preview.2` and unchanged `com.brendigo.systivra` identity.

## Testing and design acceptance

- The immutable release workflow must pass Android Lint, unit tests, instrumentation, a real APK + AAB build, application version verification, independent 390 × 844 screenshots and original SVG comparisons, responsive captures, genuine cold-start Splash, ZIP integrity and SHA-256 verification.
- All 37 original SVGs remain **concept references**, not actual app screenshots. Rendered text/icon glyphs may differ between SVG font engines and Android's system fonts. No decorative graph is represented as a real reading.
- **Full 1:1 certification is not complete** while Android system UI, font rasterization, unsupported device APIs and data-dependent visualization differ. Screen-by-screen manual sign-off and physical-device validation remain necessary.
- The debug APK uses the disposable developer debug key; the AAB is **unsigned**. Neither is a production-signed Google Play update.
- Previous release assets are not overwritten.
