# SYSTIVRA v0.12.0-preview.4 — readable typography and dark-mode interactive states

**Android development preview**. New build of the real SYSTIVRA app, not an SVG mock-up and not a production-signed Google Play update.

## Typography and 1:1 design work

- Original 390×844 SVG references specify Arial glyphs. Real Android emulator captures with system Roboto showed a systematic horizontal discrepancy: large headings roughly **3–5% narrower**, subtitles roughly **1.5% narrower**, and the muted 13sp captions about **5% wider**. Adjusted the shared native Compose text glyph horizontal transforms toward the source artwork **without altering previously validated vertical baselines or touch geometry**.
- Matched shared row label geometry to its reference with a small x shift and 2% narrower 16sp glyph transform. Headline, subtitle, hero-brand and row text now use explicit high-contrast design ink.
- Kept the reference's midnight gradient, 3D ring, 69dp cards, 18dp vector symbols, background/accent tokens, navigation, 34dp icon tiles and existing 1dp baseline regression checks. Unchanged original SVGs remain the reference.
- The source references use an Arial font the Android system does not ship. Geometric calibration improves specific measurements but is **not a substitute for a licensed embedded font** or physical-device approval. Never represent a snapshot as certified 1:1 just because CI passed.

## Readability / user interface

- Defined explicit Material 3 dark foreground/background color roles for surfaces, raised cards, secondary containers, dialogs, filled buttons, error states, and disabled / selected controls.
- Corrected all **five** actual Android AlertDialog entry points to use readable light labels/body ink over raised midnight surfaces.
- Corrected the search field in device metric details: light text, labels, placeholder and focused/unfocused border/cursor colors instead of inherited dark input styles.
- Settings Units Celsius/Fahrenheit controls now have accessible foregrounds in their selected, unselected and disabled states, with a dark blue selected background; persisted units and real Android reading conversions from the previous release remain intact.
- Preserved the high-contrast **dark-on-bright** ink in cyan and mint filled actions. This is deliberate and legible; black/dark text on midnight panels is not allowed.
- Matched the original #8B5CF6 Purple in its SVG graphics, while using a darker interactive violet role where white labels need at least 4.5:1 contrast.

## New automated quality gates

- JVM contrast tests require **WCAG 2.2 AA 4.5:1** minimum foreground/background contrast for 17 key label roles, including dark panels, cards, primary/secondary buttons, muted bottom tabs and error surfaces.
- Connected Compose UI tests inspect the effective rendered foreground of cards, dialogs, buttons and interactive selected/unselected chips, rather than testing palette declarations alone.
- Native 390×844 screenshot QA checks the readability of the **title, subtitle and caption on all 36 original non-Splash in-app reference routes**. Pixel and layout comparisons with the unmodified SVG source remain enabled, including the existing tight baseline audit.
- Additional untouched screenshots capture **Appearance, Update interval and Units modal dialogs**, plus **disabled report export controls**, at the exact 390×844 emulator viewport. These four states are archived separately from the immutable 38 screenshot source-reference package.
- Retained 63 route navigation, responsive screen tests at 360×800, 412×915 (130% font), 600×960 and 800×1280, and genuine cold-start Splash QA.

## Security and scope

- Preserved v0.12.0-preview.3 security/dead-code hardening: atomic bounded recording queue, Android 12+ backup/device-transfer exclusions, safe sanitized error text, explicit no-cleartext policy, no INTERNET permission and private SQLite data.
- **0/37 screens independently certified pixel-perfect**: real-device font rasterization, platform bars, dynamic measurements, focus/pressed/TalkBack states on physical hardware, and full manual review are pending. This preview does NOT claim a finished app or a complete external security audit.
