# SYSTIVRA v0.6.0-preview.1 — Session Insights & JSON Export

**Android developer preview. Not a production-certified or Google Play-ready build.**

## New functionality
- **Session Insights:** battery charge graph derived from actual recorded samples, percentage range/mean/net change, observed temperature range/mean and Android thermal-state counts.
- **Availability-safe statistics:** missing values remain unavailable. The sampled net change rate appears only when at least two valid battery readings are one minute apart. It is not a battery health, capacity or charging-efficiency measurement.
- **JSON export:** choose an Android Files destination for a structured v1 JSON document containing timestamp, battery, thermal, RAM and optional CPU activity. Missing metrics use JSON null and the exporter escapes control characters. No device identity is deliberately included.
- **CSV remains available:** both formats are exported only after user action, without network permission or automatic upload.
- **Unit tests:** real time-window arithmetic, invalid/missing values, JSON escaping and privacy-oriented report contents.
- **Visual QA update:** the workflow captures 36 original in-app screens plus Recording Library and Session Insights. The transient Android system Splash is excluded from ordinary route screenshots and needs its own startup capture.

## Release assets
- SYSTIVRA-v0.6.0-preview.1-debug.apk — debug-signed Android development APK.
- SYSTIVRA-v0.6.0-preview.1-unsigned.aab — unsigned bundle, **not ready for Google Play**.
- SYSTIVRA-v0.6.0-preview.1-source.zip — tagged source tree including app, website, branding, docs and QA.
- SHA256SUMS.txt — SHA-256 checksums for all release files.

## Verification and limitations
The release workflow must pass Kotlin compilation, unit tests, Android instrumentation **compilation**, APK building and AAB bundling before publication. Emulator instrumentation and 1:1 pixel comparison are independent gates.

**No 1:1 visual certification has been achieved for all 37 original designs.** Recording Library and Session Insights still require approved design baselines. Physical-device tests, accessibility review, full dead-code/security audit, advanced hardware diagnostics and signed Play distribution remain incomplete.

English-only, dark by default, system Splash -> Dashboard, no account or onboarding.
