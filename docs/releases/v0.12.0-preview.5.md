# SYSTIVRA v0.12.0-preview.5 — per-format export feedback and spreadsheet safety

**Android developer preview** of the existing native app; not an SVG mock-up or a production-signed Play update.

## Changes
- Fix the bottom app tabs touching/overlapping Android's system gesture/three-button navigation bar. Reserve the actual `WindowInsets.navigationBars`, keep every clickable tab at 62dp, and introduce an 8dp dark separation gutter above the native system controls. The system navigation background is darker than the 62dp tab strip, with explicit light system icons on older Android versions. An instrumented bounds test checks both inset and gutter. The Android system controls are not imitated.
- Correct a functional UX defect: CSV, JSON, PDF, and Android Sharesheet display export/cancellation/error status inside the **corresponding** card. Earlier a JSON/PDF/share outcome appeared under the CSV Export card.
- Preserve default layout: JSON/PDF/Sharesheet feedback appears only after a related action; existing first-paint screen geometry is not shifted.
- Harden CSV formula escaping for leading BOM, zero-width Unicode format characters, Unicode word joiners, whitespace and control characters; preserve original sensor/vendor reading text and CSV quotation.
- Add focused JVM regression tests for those prefixes, spreadsheet formulas and normal quoted Unicode data.
- Bump to `versionCode 19`, `versionName 0.12.0-preview.5` with unchanged `com.brendigo.systivra` identity.
- Resolve PR #36 CI failures without relaxing tests: move API-27-only system-navigation icon flag into `values-v27/styles.xml` while maintaining the API 24 shared theme; preserve Android Lint as a hard gate. When UTP cannot download published JUnit Platform 1.13.3 metadata, retry only that exact resolution failure once with refreshed dependencies. Real instrumentation failures remain blocking and original runner logs are archived.

## Release acceptance
Do not publish until exact-commit Android lint, JVM tests, emulator UI tests, full 390×844 Android-vs-original SVG diagnostic comparison, four responsive viewports and true cold-start Splash QA all pass. SVGs and genuine screenshots must not be modified to improve scores. No release is considered published until the GitHub Release and assets exist.

## Deliverables (only after release passes)

## Limitations

Full independent device penetration testing, transitive dependency CVE audit, and production key signing are outstanding. No INTERNET permission, account, fabricated device metrics or broad storage access is introduced.
