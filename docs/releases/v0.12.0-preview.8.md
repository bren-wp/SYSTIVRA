# SYSTIVRA v0.12.0-preview.8 — Focused Export, Recording and Permission Screens

**Native Android developer preview — NOT a production-signed Play bundle or pixel-perfect certification.**

## Usability and functional changes
- **Reports & Export:** selecting CSV, JSON, PDF or Android Sharesheet in the approved SVG reference first viewport opens only the relevant functional export panel. No automatic scroll through four stacked cards. The selector is a two-row, 2×2 set of accessible Compose FilterChips for narrow phones and enlarged fonts. Users can change format without triggering a picker.
- **Empty export state:** a clear message explains no saved samples are available and provides a real Open Recording shortcut. Export buttons remain disabled until samples exist. CSV/JSON/PDF/Share outcomes (cancel/progress/failure/success), privacy safeguards and Storage Access Framework document pickers are preserved.
- **Recording Session:** Start/Pause still toggle actual app-private foreground capture. Tapping Duration or Storage Policy opens a short source-labeled dismissible status dialog instead of scrolling beyond a 116dp spacer. Full controls and saved recordings remain on dedicated screens. Storage errors remain visible.
- **Permission Center:** tapping a reference permission row opens a concise source-labeled dialog, preserving access to a dedicated permissions screen. No forced scroll or redundant below-fold cards.
- Original 390x844 reference SVGs, default midnight palette, source readings, accessible 62dp app tabs and 8dp Android gesture/3-button navigation safety gutter remain unchanged.
