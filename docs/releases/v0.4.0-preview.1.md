# SYSTIVRA v0.4.0-preview.1 — Persistent device history

**Developer preview — unsigned AAB and debug-signed APK, not production-certified.**

## What's new

- Recording is still explicitly user-started and stops sampling when the app goes to the background.
- Added a private on-device SQLite database for up to 900 recorded metric samples.
- Saved recordings now survive app restarts and can be cleared manually; Android backup remains disabled.
- Reconstructed recordings keep their original battery, temperature, available RAM, thermal and CPU activity values, without inventing missing metrics.
- The Monitoring and Recording screens distinguish temporary live samples from saved data, and CSV exports use saved records.
- Serialized recording operations avoid insert/clear interleaving; local history loading and failure messages are visible.
- Added persisted-reading unit tests and Android database reopen/clear instrumentation tests.
- Updated README and privacy policy to accurately describe retention and user control.
- Revised screenshot automation after the Android 35 emulator's ADB broken-pipe issue; now uses Android 33, captures app screens separately from UI tests and does not label a Dashboard capture as Splash.

## Remaining engineering work

The 37 screen design concepts exist but their true 1:1 visual similarity has **not** been certified. Confirmed pixel-diff artifacts from a real emulator and physical devices are still required; the system splash needs separate capture methodology. Multi-session grouping and history pagination are not implemented; only the most recent 900 entries are saved. Cross-app HUD, broader hardware diagnostics, privileged temperature sensors, accessibility/device coverage and full security audit are not complete.

This milestone verifies build and Android test *compilation*. Actual on-device tests are a separate gate; check the Android screen QA workflow for its observed status.

The app does **not** include user sign-in, onboarding, fabricated health/performance scores, or a mandatory server.
