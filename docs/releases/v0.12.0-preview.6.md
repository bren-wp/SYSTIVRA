# SYSTIVRA v0.12.0-preview.6 — navigation accessibility and visual color verification

**Native Android developer preview**, not certified 1:1 or production signed for Google Play.

## Changes
- Maintain the original SVG 62dp app tab height and anchors, reserve Android navigationBarsPadding and a visually distinct 8dp gutter above Android gesture/three-button controls. Add a full-app bottom-inset regression beyond prior isolated unit tests.
- Provide proper selected-tab accessibility semantics via Compose `selectable` without changing the dark reference design. Verify tab selection via instrumented emulator tests.
- Generic reference-first hero cards now launch each screen's primary real function rather than an unrelated Device & Android screen. Add real emulator tests for Reports/CSV and Network details hero actions.
- Retain Preview 5's functional CSV/JSON/PDF/Sharesheet destinations, per-format status messages, and CSV formula-injection defenses.
- New `report-surface-luminance.py` measures signed native-vs-original SVG brightness of heading, hero/chart, and controls for all 36 in-app reference screenshots. No global arbitrary brightness adjustment, no original SVG edits.
- Separately compare a safely detected app-owned 62px tab strip with SVG coordinates while preserving unmodified full-screen pixel differences and native Android OS controls. If the strip cannot be unambiguously identified, report it instead of faking parity.

## Required release gate
Publish only when the same exact source SHA passes Android lint, JVM unit tests, actual emulator navigation + interaction tests, 38 genuine 390×844 Android screenshots, original SVG comparison, signed-luminance report, four responsive viewports including enlarged fonts, actual cold-start Splash, security/dead-code checks, and checksum validation. Never weaken tests to force a green release.

## After successful gate
Deliver debug-signed APK, unsigned AAB, exact source ZIP, artwork, unedited emulator screenshots and interactive dialogs, separately identified original reference previews, and SHA-256 hashes.

## Still outstanding
37/37 screens need physical-device independent visual sign-off. CI visual reporting is diagnostic and does not establish zero pixel differences. Android API 24–36 OEM/gesture and three-button navigation, independent vulnerability audit, full accessibility acceptance, and production signing still need verification. No fabricated hardware readings or network-only dependency is introduced.
