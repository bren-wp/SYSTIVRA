# SYSTIVRA v0.12.0 Preview 11 — Developer Test Build

Released from merged `main` source. This is an **experimental developer preview**, not a production/Play Store release or pixel-perfect/physical-device sign-off.

## Included

- Debug-signed installable APK (`com.brendigo.systivra`, `versionCode 25`, `versionName 0.12.0-preview.11`).
- **Unsigned AAB** for developer build validation; it is **not suitable for direct Google Play upload without authorized app signing**.
- ZIP of the exact source commit, Google Play artwork, original reference designs **explicitly not represented as app screenshots**, and `SHA256SUMS.txt` for download integrity.

## Verified before publication

The APK and AAB are copied unchanged from [successful Android CI #44969477541](https://github.com/bren-wp/SYSTIVRA/actions/runs/44969477541) on source commit `817ff2400b7eb1d68a15a6a8661ba31255dc4e33`. That run passed Android lint, JVM tests, Android instrumentation **compilation**, debug APK assembly and unsigned AAB bundling, the static security/dead-code audit, and app-ID validation. The publisher checks that **no Android source differs** between that source SHA and the release commit, tests ZIP integrity, validates package metadata and writes SHA-256 checksums.

## Pending, not certified

- The full connected-emulator interaction tests were still running when fast publication was prepared.
- The exact-release-commit 38 native-screen captures, original-vs-app visual diff, responsive four-viewport checks and genuine Splash capture are separate QA and are **not represented as passed** by this fast developer build.
- The app remains **not certified 1:1 pixel-perfect** on physical devices or approved by Google Play. See [visual QA issue #26](https://github.com/bren-wp/SYSTIVRA/issues/26).
- No proprietary release signing keys are included.

Use this preview for testing while the rigorous QA workflow continues independently. Defects found in native UI, accessibility or performance must be corrected in a later version, not silently overwritten under this immutable tag.
