# SYSTIVRA v0.10.0-preview.1 — Reference-based UI development

**DEVELOPER PREVIEW — design parity is not yet certified.**

## 37 original reference designs
- All 37 SVG reference screens are preserved in the repository.
- Every original 390×844 design is adapted to an opaque **1080×1920 PNG** without distortion/cropping, with side letterbox margins only.
- Complete [37-design reference ZIP](../../brending/google-play/reference-previews-NOT-PLAY-SCREENSHOTS/SYSTIVRA-37-REFERENCE-PREVIEWS-1080x1920.zip), hash manifest and contact sheet delivered.
- These are **design references, not screenshots of the running Android app**. They must **not** be uploaded to Google Play as actual screenshots.

## Native Android alignment
- Dashboard and Hardware Explorer redesigned toward original header, four card rows, ring branding, layout sizes and colors.
- Live Monitor and Diagnostics Center adopt the reference screen structure, preserving live Android measurements and working control routes.
- Text-only 62dp bottom navigation and a background gradient more closely match original references.
- Additional functions remain accessible below the initial view instead of being removed for visual appearance.
- Added an actual user-triggered speaker tone diagnostic test, with manually confirmed results; no audio recording or microphone access.
- Navigation test expectations updated to match the UI.

## QA and implementation status
- Fixed invalid GitHub Android workflow YAML that had blocked builds; release compilation and lint are mandatory.
- Visual CI compares original references against actual device captures; 1:1 claims require per-route diffs, font/inset measurements, and human review.
- **No 37/37 pixel-perfect claim is made**. Some screens remain only partly implemented, and emulator/device tests are still required.
- Package is **com.brendigo.systivra** only.
- No artificial sensor metrics or fake app screenshots.

## Downloadable build
- Development-debug APK; unsuitable for production signing
- Unsigned Android App Bundle; must be signed and tested for Google Play
- Full source ZIP containing editable reference screens and docs
- Branding ZIP and original 37 reference design ZIP
- SHA256SUMS.txt for all release artifacts

Full Play publication requires genuine reviewed screenshots, public HTTPS privacy policy, Data Safety and Usage Access reviews, signed release bundle and Android device test coverage.
