# SYSTIVRA v0.12.0-preview.9 — Navigation, Recording Integrity and Focused Tool Catalog

**Native Android developer preview**. It is not an independently signed or certified 37/37 1:1 Google Play release.

## User-facing changes

- **Focused searchable tool categories** in the functional Screen Catalog: All, Hardware, Monitor, Tests, Records and System. Two rows of three phone-width FilterChips reduce excessive vertical scrolling through many unrelated tools. Category and search operate together, and a Show all tools action resets an empty result. Disabled routes never become accessible. Original 37 SVG reference layouts are not altered.
- **Cycle-aware Android navigation:** if a user revisits an existing screen, return to that entry rather than stack duplicate pages. Primary bottom tabs still replace the root. Safeguard Android saved state from indefinitely growing stacks by retaining the initial root and last 23 screens (max 24), preserving normal back behavior in current history. The app still has no login and no new permissions.
- **SQLite recording hygiene and privacy:** Starting then immediately stopping a private recording before the first sample no longer leaves invisible empty session rows. Update and cleanup are transactional. Completed empty rows left by older versions are cleaned when the DB is opened, while **active zero-sample sessions and all sessions containing genuine samples are preserved**. No database schema migration or cloud API is added.
- **Maintain Preview 8** CSV/JSON/PDF/Share focused export, accessible buttons and recording shortcuts, genuine Android values, accessible bottom tabs, and Android gesture/3-button safe area with 8dp separation.

## Automated acceptance / release gate

- New pure JVM tests exercise 250 sequential screen hops with root preservation, revisits, tab resets and back-stack bounds, plus catalog category/search and unavailable routes.
- New connected Android SQLite tests assert that 40 start/stop cycles produce zero orphan rows, and that opening a legacy database removes only ended empty sessions while retaining unfinished and sampled sessions.
- Updated Compose emulator interaction test navigates Hardware and Records catalog categories, uses lazy scrolling to find real rows, and resets impossible search.
- Preview artifacts publish **only** on exact HEAD after Android lint, JVM tests, compile and connected instrumented Android suite, security/dead-code and route audits, genuine 38-route 390×844 screenshot vs original SVG pixel/brightness comparisons, four responsive viewports including enlarged fonts, real cold-start Splash video and SHA256 package validation.
