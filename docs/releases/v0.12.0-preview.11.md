# SYSTIVRA v0.12.0-preview.11 — Focused Screens and Maintainability

**Developer test preview**, with full Android CI gates. Production signing, physical-device acceptance and independent 37/37 pixel-perfect certification remain outstanding.

## User-facing improvements

- **No vertical scrolling in composed UI source:** all 38 current Kotlin UI files were inspected for `LazyColumn` and `verticalScroll`, neither remains. Reference-first boards preserve four prominent actions and source-aligned spacing. Functional screens use clear in-app sections, dialogs or **Previous / Next** pages instead of an endless feed.
- **Focused navigation:** Dashboard, Hardware Explorer, Settings and About now show four primary reference rows and a hero area opening accessible secondary actions. Monitor, Diagnostics, Recording Session, Permission Center and Charging Analysis follow the original first-view structure; underlying tools remain reachable.
- **A page for each task:** filtered tool catalog; Android readings; session history with date windows; saved recordings with analyze/insights/export/delete; recording controls; per-session analytics; benchmarks; private report exports; network, CPU, sensor, thermal, privacy, alerts, HUD preview, usage and permissions.
- **Actual measurements only:** sensors remain Android SensorManager-driven, network bandwidth remains explicitly an estimate, CPU test stays bounded and cancellable with a thermal cutoff, and recording data is app-private SQLite. No unsupported metrics are fabricated.
- **Refactoring:** split legacy ~65KB `AppRoot.kt` into smaller focused Kotlin modules with shared pager/UI primitives. All Kotlin and Python/shell tooling source files have leading brand attribution while preserving interpreter shebangs.
- **Source-level dependency compatibility:** attempted Compose BOM 2026.11.01 produced a real AAR metadata failure because Compose 1.13 requires compileSdk 37.1+. With current build/CI at 37.0, kept Compose BOM 2026.09.00; updated AndroidX Lifecycle runtime to stable 2.11.1. Full dependency security scan/SBOM still required for production.

## QA acceptance

All tests must run on the **exact release commit**:
1. Android Gradle lint, JVM and instrumented Android emulator suites (navigation, privacy, exports, measurements and saved sessions).
2. Real native captures for 38 routes at 390×844; 36 source SVG in-app comparisons plus genuine cold-start Splash video and original RGB geometry checks.
3. Four responsive device captures including 130% font and Android system-navigation safe areas.
4. Deterministic static security/dead-code/source-route checks, SHA256SUMS and immutable release tag.

**Passing CI does not certify 1:1 pixel-perfect across all references.** Individual visual review of typography, geometric offsets, OS insets and physical Android OEMs remains tracked in [issue #26](https://github.com/bren-wp/SYSTIVRA/issues/26).

## Packages after the gate

Debug-signed APK for on-device testing; **unsigned AAB** that requires authorized Play signing; exact source ZIP; genuine emulator screenshots, modal evidence and reference/design material in separately labeled archives; artwork and SHA256SUMS. No production signing secrets live in this repository.
