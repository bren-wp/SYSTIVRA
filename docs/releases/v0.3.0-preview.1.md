# SYSTIVRA v0.3.0-preview.1 — Android developer preview

**This is a developer preview, not a production-certified release.** It builds an installable debug APK and an unsigned AAB. Google Play requires authorized app signing, manifest and policy review.

## Implemented since v0.2.0-preview.1

- Live sensor readings through SensorManager, including axes, units, metadata and automatic listener cleanup.
- Network state and platform bandwidth estimates using ACCESS_NETWORK_STATE, without INTERNET permission.
- Optional Android Usage Access screen (permission requested only via Settings) and local UsageStats when authorized.
- On-screen battery and thermal warnings with locally saved thresholds.
- User-started foreground recording in memory (maximum 900 samples), summary statistics and CSV export.
- CPU microbenchmark: bounded to two seconds, cancellable, thermal-state cutoff and measured operations per second.
- GPU renderer/vendor/OpenGL ES from a temporary hardware driver context, cached and sampled off the main UI thread.
- CPU activity from /proc/stat only where readable; unavailable is not interpreted as zero.
- Additional battery voltage, Android-reported health and display refresh-rate data.
- User-confirmed diagnostic results persisted locally and configurable measurement intervals.
- Functional in-app Performance HUD preview; cross-app floating window is **not** implemented.
- Automated debug-route screenshot capture and image-difference reporting tools.
- New unit tests for CPU activity parsing and existing CSV correctness.

GitHub also creates its standard source archives for the tag.

## Open items and acceptance criteria

- **37 reference designs exist**, and their corresponding Android routes or system splash are accessible; many are still partial features.
- **Pixel-perfect 1:1 has not been validated.** Emulator screenshot and pixel-diff evidence must be reviewed per route; 1:1 status remains unverified.
- No permanent Room history; recording remains bounded in memory. No background monitoring or cross-app overlay.
- Camera, microphone, speaker tests and GPU FPS/global utilization are not finished.
- Different Android devices restrict CPU/GPU temperatures, App Usage Access and other statistics; no unavailable metric is faked.
- Full manual security audit, dead-code audit, Play Console policy verification, accessibility and physical-device regression testing are still required.
