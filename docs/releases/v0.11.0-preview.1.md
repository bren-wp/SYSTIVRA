# SYSTIVRA v0.11.0-preview.1 — real reference parity and device diagnostics

**ANDROID DEVELOPER PREVIEW** — actual APK/AAB and source artifacts. **Not a production-signed Google Play release** and **not certified pixel-perfect**.

## In this release

- Rebuilt **Metric Fullscreen, Privacy Center, System Health, Sensor Live View and Benchmark Center** to follow their original 390×844 SVG compositions: correct titles, captions, 128dp hero or 170dp chart and accurate 69dp action rows.
- Preserved the actual Android data controls as independent routed detail pages: real battery timeline, Android framework system health readings, private storage/privacy details, live SensorManager sampling and explicit CPU microbenchmark controls.
- New drilldowns use **real battery percentage data**, Android service availability and explicit unavailable states. Synthetic sensor-axis charts, fabricated performance results and unimplemented memory/storage benchmark scores are not emitted.
- CPU benchmark remains **single-worker, bounded to approximately two seconds, cancellable and thermally guarded**. Memory and storage benchmarks remain marked unsupported.
- Navigation retains system Back and the original tab bar; original reference headers now carry **screen-reader heading semantics**, buttons and tabs expose appropriate roles, selected tabs expose their selected state, and oversized text is ellipsized rather than spilling outside rows.
- Expanded pure unit tests, Android Compose interactions and cross-route smoke coverage for the five newly aligned destinations. New versionCode **13** and versionName **0.11.0-preview.1**; application ID stays `com.brendigo.systivra`.

## Verification and remaining work

- Gate this release on Android Lint, all unit tests, instrumented emulator tests, genuine 390×844 screenshot captures/diffs and artifact identity/checksums. Run the independent multi-viewport and real cold-start Splash QA as additional diagnostic evidence.
- Original SVG drawings are **design references**, not genuine Android screenshots; decorative concept graphs must not substitute for measured readings.
- Full **1:1 approval for all 37 source references is still pending**. System status bars, fonts, device density and individual chart data vary.
- **No physical Android device has been verified in this iteration.** The checked-in opt-in ADB script is for use on authorized devices, not proof of execution.
- Debug APK is signed using a disposable Android debug key for local testing and is **not suitable for Google Play update signing**.
- Release AAB is **unsigned**. Publishing to Google Play requires the owner's protected app-signing configuration and signed AAB; no signing key is embedded in source or CI.
- No new background service, account registration, INTERNET permission or analytics SDK.
