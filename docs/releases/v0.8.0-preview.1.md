# SYSTIVRA v0.8.0-preview.1 — Stable dependencies, privacy and Play capture QA

**Developer preview; not Google Play production-ready.**

### Android upgrades and stability
- AGP 9.4.0 (compatible with Gradle 9.6.0), AndroidX SplashScreen 1.2.0; other AndroidX/Kotlin libraries remain on verified stable releases.
- Added Dependabot weekly upgrade proposals and an auditable dependency version inventory.
- Added optional Usage Access consent explanation *before* redirecting to system settings.
- Added defensive sensor registration/unregistration handling for device-specific failures.
- Added an accessible Privacy Center link from About.
- Added Android lint to CI and release preflight; build and instrumented-test compilation must pass before publication.

### Google Play materials
- Complete editable brand source and PNG icon (512×512, RGBA) and feature graphic (1024×500, RGB).
- Eight 1080×1920 concept posters remain in **concepts-NOT-FOR-PLAY** and must never be uploaded as screenshots.
- Real app captures are accepted only after Android focus/ANR checks and exact 1080×1920 source dimensions; no generated UI image or upscaled concept is used.
- English listing text, permissions/Data Safety/target API checklist, icon, feature art, branding ZIP and source code in the repository.

### Release assets
- SYSTIVRA-v0.8.0-preview.1-debug.apk (debug signed)
- SYSTIVRA-v0.8.0-preview.1-unsigned.aab (not Play-ready)
- SYSTIVRA-v0.8.0-preview.1-source.zip (full source)
- SYSTIVRA-v0.8.0-preview.1-play-artwork.zip (brand assets)
- SHA256SUMS.txt

### Open acceptance gates
No authentic screenshots have yet passed the full capture-and-manual-review process. All screen references remain **not certified 1:1**. Google Play Console approval, private-key signing, accessibility, performance, real-device crash/ANR tests, privacy/Data Safety and full security audits require independent verification. Any unavailable hardware metric is clearly marked rather than fabricated.
