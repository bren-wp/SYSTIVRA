# SYSTIVRA v0.2.0-preview.1

**Android developer preview — not production certified.**

### What's new
- Reworked navigation and dashboard live battery activity.
- System Health, Privacy Center, CPU Core Inspector, Charging Analysis.
- Battery graph from actual foreground samples.
- Explicit CSV report export using the Android Storage Access Framework.
- Marketing README with brand imagery and 37 screen design references.
- CSV correctness tests and CI packaging.

### Assets in this release
- SYSTIVRA-v0.2.0-preview.1-debug.apk — **debug-signed** development APK for installation and functional testing.
- SYSTIVRA-v0.2.0-preview.1-unsigned.aab — **UNSIGNED** release bundle; must be signed before Google Play submission.
- SYSTIVRA-v0.2.0-preview.1-source.zip — exact full source at the release commit, including app, website, branding and docs.
- SHA256SUMS.txt — file integrity manifest.

GitHub also supplies its native source ZIP and TAR.GZ for the tag.

### Verification and warnings
Android compilation, JUnit tests and bundling are prerequisites enforced by the release workflow; release publishing fails if these fail.
The design boards are concepts, not real on-device screenshots. A 1:1 pixel comparison is not yet complete and must not be claimed.
No password, keystore or signing key is stored in the repository.
Some device metrics and diagnostic modules remain unavailable depending on Android version and hardware.
