# SYSTIVRA visual identity v0.1

**Brand:** SYSTIVRA — Advanced Device Monitor & Diagnostics  
**Language:** English only  
**Launch flow:** Splash → Dashboard (no account, login, registration, or onboarding)

## Palette
- Midnight: \`#0B121E\`
- Deep navy: \`#0F1B30\`
- Card: \`#152235\`
- Card elevated: \`#1A2D47\`
- Cyan: \`#29C7FC\`
- Purple: \`#8B5CF6\`
- Mint/healthy: \`#32E5BC\`
- Text: \`#F4F8FC\`
- Muted: \`#9CAFBE\`
- Warning: \`#F4B860\`
- Error: \`#EF6678\`

## Geometry
Base spacing 4 / 8 px (Compose dp); 16–20 px cards; 16 px phone gutters; minimum touch target 48dp. Use tabular numeric figures. Prefer 24px icons, medium/semibold labels, unobtrusive 1px strokes.

## Architecture
1. Components: cards, metric rows, progress rings, availability tags, charts, bottom nav.
2. Screens: Splash and 36 in-app destinations. Every mockup carries an English title.
3. The dashboard and details must reflect **actual available readings**; unsupported values must be marked **Unavailable**.
4. Display the recorded source/quality for readings; do not infer CPU/GPU temperature without access.
5. Separate illustration assets from production screenshots.

## 1:1 acceptance
Exact-match target is **not certified** by these source SVG files. Compare real screenshots at controlled resolutions, font scaling, status/nav bars and Android versions. Log per-screen pixel-diff metrics and remediate before stating zero deviation.
