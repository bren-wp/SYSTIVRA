Privacy information

Development preview — updated November 2026.

The current Android foundation is designed to inspect local device state without an account, advertising SDK, analytics SDK or mandatory backend. It uses Android system APIs to read available battery, memory, storage and sensor information.

Data collection

Core readings are processed on the device. The planned local-history feature must store metrics locally. The current project does not include account creation or server-side telemetry.

Permissions

Core monitoring needs no dangerous Android permissions. Future microphone, camera, notifications and overlay features must request explicit permission when used; rejecting an optional permission must not block the app.

Data sharing

Future report sharing must occur only after the user explicitly chooses it. External links (such as GitHub) are operated by their respective providers under their own privacy policies.

Contact & changes

For questions or corrections, open an issue at GitHub Issues. Review this policy again before a public production release; it describes the current source design, not a third-party privacy audit.
